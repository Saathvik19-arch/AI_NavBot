IIITDM-NavBot: Multi-Paradigm Autonomous Campus Navigation, Logistics, and Conflict Resolution System using Uninformed Search, Heuristic Search, Local Optimization, Constraint Satisfaction, and Adversarial Game Search.



Navigating modern educational campuses requires more than simple point-to-point pathfinding. Autonomous delivery and travel bots on the IIITDM Kancheepuram campus must address multiple complex operational challenges, including dead-end road terminations (such as parking spurs ), mandatory checkpoint stops (such as the Library ), multi-destination delivery tours, and bottleneck corridor negotiations.
